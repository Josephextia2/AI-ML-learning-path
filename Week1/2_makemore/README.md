1. Think clear about the logic how the neural network learn from the input data.
    Ans: The model is trained by medium-large data set, and noted that the bigram actually is the probaility of the next character. DP procedure, xenc @ W and prob = counts / counts.sum(1, keepdim=True), tries to reproduce the bigrams, which is comparable to the figure exactly plotted by the input names. In the Deep learning process, it first guesses the bigrams via the 1st character to obtain the guessed probability of the next character. Then, compare to the actual next character and adjust the weights and bases (via minimize the loss) to obtain the close probailities/bigram. That's why the names predicted via the model are the same as the names generated by using actual data.

3. Think about how to address the learning rate so that it could be faster but stable?
    Ans: In this HW, the learning rate is 100 * exp(-j/100), where j is an iteration. This function makes sure the learning rate is decreasing according to training time. At the beginning, the initial guesses might too far away from its minimum, so the learning rate is large. It is expected that the loss is graduately approaching to zero and the learning rate should be smaller automatically so that it will not jump over the minimum values. Exponetial decay is chosen instead of mannally control the learning rate by if condition because of efficiency and stability, as it is gradually decreased but not a sharp change.
